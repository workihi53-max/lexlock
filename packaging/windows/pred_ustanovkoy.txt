ЛексЛок — офлайн-помощник юриста. Всё ставится на ваш компьютер, без сервера.

Куда ставится
  Папка по умолчанию: C:\Users\<ваше имя>\AppData\Local\LexLock
  (её можно поменять на следующем шаге «Папка установки»).
  Права администратора не нужны. Ваши документы лежат отдельно:
  <папка установки>\workspace — они никуда не отправляются.

Что ставится (по шагам)
  0. Свежий код подтягивается с GitHub (ветка main) — правки, вышедшие после
     сборки установщика, тоже попадут. Не получилось скачать — ставится код
     из установщика, установка не прерывается.
  1. Файлы программы — копируются в папку установки.
  2. Python-окружение (.venv) — только для ЛексЛока, ваш Python не трогаем.
  3. Ollama — программа для запуска модели локально.
  4. Языковая модель (qwen2.5, около 1–2 ГБ) — подбирается под вашу память.
  5. Tesseract для чтения сканов (если получится; без него всё равно работает).

Сколько ждать и что нужно
  Нужен интернет — только один раз, во время установки (качается ~2 ГБ).
  Дальше интернет не нужен: приложение работает полностью офлайн.
  По времени: обычно 5–15 минут в зависимости от скорости.

Если что-то пошло не так
  Установщик сам скажет об ошибке и покажет файл install.log в папке установки.
  Просто запустите повторно ярлык «Установить компоненты» из меню «Пуск → ЛексЛок».

Нажмите «Далее», чтобы продолжить.
