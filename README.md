# ЛексЛок — офлайн-помощник юриста

**▶ Видеопрезентация (20 секунд)** — нажмите на кадр, чтобы посмотреть.

## Что это — простыми словами

**ЛексЛок** — программа для юриста, которая работает целиком на вашем компьютере и
**никуда не отправляет ваши документы**. Внутри неё — искусственный интеллект (языковая
модель), который живёт прямо на вашем ноутбуке, а не в интернете.

Вы загружаете договор, паспортные данные или скан — ЛексЛок сам находит в них важное
(стороны, даты, суммы, реквизиты), заполняет договор и подсказывает, на что обратить
внимание.

Интернет нужен **только один раз** — при установке, чтобы скачать модель. Дальше можно
выключить сеть: всё продолжит работать.

Демо для акселератора 2026. Работает на обычном ноутбуке, видеокарта не нужна.

## Офлайн-пакеты (рекомендуется при плохом интернете)

Самодостаточные сборки: внутри Python, Ollama и модель, при установке ничего не качается.
Собираются `scripts/build_offline.sh <windows|linux|macos>` или workflow «Offline bundles».

- **Windows:** `LexLock-*-win-offline.zip` — распаковать, запустить «Запустить ЛексЛок.bat».
- **Linux:** `LexLock-*-linux-offline.AppImage` — `chmod +x` и запустить (без FUSE: `--appimage-extract-and-run`).
- **macOS:** `LexLock-*-mac-*-offline.dmg` — перетащить в «Программы», первый раз «Открыть» правым кликом.

## Зачем это нужно

Юристу нельзя отправлять документы в обычные онлайн-сервисы (ChatGPT и подобные), потому
что в них — персональные данные, коммерческая тайна, а иногда и гостайна:

- **152-ФЗ «О персональных данных»** — паспорта, ИНН, адреса;
- **NDA и коммерческая тайна** — договоры, реквизиты, суммы;
- **служебная и государственная тайна** — работа вообще без внешних сервисов.

ЛексЛок решает эту задачу: документы остаются у вас, ничего не уходит наружу.

## Что умеет

1. **Заполняет договор.** Загрузили паспорт и реквизиты — получили готовый договор с
   подставленными данными. Работает мгновенно и без интернета.
2. **Читает сканы и фотографии.** Сфотографировали документ или отсканировали — ЛексЛок
   распознаёт текст и приводит его в порядок.
3. **Разбирает документ.** Говорит, что это за документ (договор, паспорт, реквизиты,
   доверенность, претензия…), кто стороны, какая дата, номер и сумма.
4. **Проверяет договор по чек-листу.** Показывает, какие обязательные условия есть, а
   каких не хватает, и на сколько процентов договор «полный».
5. **Находит подозрительные условия.** Например, автоматическую пролонгацию,
   односторонний отказ, неустойку без предела.
6. **Сверяет реквизиты.** Загрузили договор и карточку реквизитов — ЛексЛок поймает
   расхождение (например, разный ИНН в документах).
7. **Отвечает на вопросы по документу.** Спрашиваете — отвечает цитатой из текста.

## Как установить

Самый простой способ — **одна команда в терминале**. Скрипт сам скачает свежую
версию программы, поставит всё необходимое, добавит «ЛексЛок» в меню программ и
откроет его. Первый запуск скачивает модель (~2 ГБ) — это нужно один раз, дальше
всё работает офлайн.

### Windows

Откройте **PowerShell** (меню «Пуск» → наберите «PowerShell» → правый клик →
«Запуск от имени пользователя»). Вставьте и нажмите Enter:

```powershell
irm https://raw.githubusercontent.com/workihi53-max/lexlock/main/install-windows.ps1 | iex
```

### Linux

Откройте **терминал** (обычно Ctrl+Alt+T). Вставьте и нажмите Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/workihi53-max/lexlock/main/bootstrap.sh | bash
```

### macOS

Откройте **Терминал** (Finder → Программы → Утилиты → Терминал). Вставьте и нажмите Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/workihi53-max/lexlock/main/bootstrap.sh | bash
```

> **Первый запуск на любой системе скачивает модель (~2 ГБ)** — это нужно один раз.
> Дальше интернет не требуется.

## Как закрыть приложение

Просто закрыть вкладку браузера **недостаточно** — сервер продолжит работать в фоне.
Чтобы остановить ЛексЛок и освободить память:

- **Кнопка «■ Остановить»** в правом верхнем углу окна — самый простой способ;
- **иконка в трее** (рядом с часами) → пункт «Остановить»;
- либо перезагрузка компьютера.

## Как понять, что документы никуда не уходят

Просто выключите интернет (Wi-Fi или кабель) — ЛексЛок продолжит работать как обычно.
Это и есть главное доказательство: все данные остаются на вашем компьютере.

## Честно об ограничениях

- **Это помощник, а не замена юристу.** Программа извлекает факты и подсвечивает
  подозрительные места, но финальное решение — всегда за специалистом.
- Модель работает на обычном процессоре, поэтому распознавание сканов занимает
  несколько десятков секунд — это нормально.
- Тестовые документы в папке `samples/` — вымышленные.

## Для разработчиков

Проект на Python (FastAPI + Ollama). Браузер открывает локальную страницу
`http://127.0.0.1:8765`; вся обработка документов и модель — только на вашей машине,
сетевые соединения вне `127.0.0.1` блокируются принудительно.

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -e ".[dev]"
.venv/bin/python -m pytest tests -q     # тесты не требуют Ollama
./run.sh
```

Технические детали (карта модулей, инварианты, правила) — в `AGENTS.md`, контракт
интерфейсов — в `SPEC.md`.
