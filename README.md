# Ваня — локальный офлайн-ассистент для юристов

«Ваня» (Legal AI Vault) — демо-приложение: локальная LLM на базе Ollama, которая работает
полностью на ноутбуке и не отправляет данные в интернет. Веб-интерфейс, три сценария, всё на CPU.

## Зачем это нужно

Юридические документы часто нельзя отправлять во внешние сервисы:

- **152-ФЗ «О персональных данных»** — паспортные данные, ИНН, адреса.
- **NDA и коммерческая тайна** — договоры, реквизиты, суммы.
- **Политика безопасности / GDPR** — запрет на передачу данных третьим лицам.

«Ваня» держит документы и модель на вашей машине: после установки интернет не нужен,
а в режиме `VANYA_OFFLINE=1` сетевые соединения вне `127.0.0.1` блокируются принудительно.

## Требования

| Ресурс | Минимум |
|---|---|
| ОЗУ | 8 ГБ |
| Свободное место на диске | 6 ГБ (модель ~2 ГБ + окружение) |
| CPU | 4 ядра, GPU не нужен |
| Python | 3.12 (ставится автоматически вместе с `uv`) |
| Ollama | ставится автоматически скриптом `install.sh` |

## Быстрый старт (одна команда)

Установка сама подтягивает `uv`, Ollama и модель — отдельно ничего готовить не нужно:

```bash
curl -fsSL https://raw.githubusercontent.com/workihi53-max/vanya-legal-vault/main/bootstrap.sh | bash
```

Скрипт скачает проект в `~/vanya-legal-vault`, поставит окружение, Ollama и модель
`qwen2.5:3b`, затем нужно запустить:

```bash
cd ~/vanya-legal-vault
./run.sh                # запуск, офлайн, браузер откроется сам
# http://127.0.0.1:8765
```

Если репозиторий уже скачан, достаточно одной команды в его папке:

```bash
./install.sh
./run.sh
```

Установка без скачивания модели (для проверки детерминированных сценариев):

```bash
./install.sh --skip-model
./run.sh
```

Требуется только `curl` и один раз интернет. Если Ollama ставилась впервые, на macOS
один раз запустите приложение Ollama, затем `./run.sh` поднимет её сам.

## Готовые установщики

Для обычного пользователя — файлы в разделе **Releases** на GitHub:

- **macOS** — `Vanya-<версия>.dmg`: открыть, перетащить «Ваня», двойной клик.
- **Linux** — `Vanya-<версия>-x86_64.AppImage`: один файл для всех дистрибутивов.
- **Windows** — `Vanya-<версия>-win-setup.exe`: обычный установщик с ярлыками.

Как собирать самому — `packaging/README.md`. Все установщики ставят `uv`, Ollama и
модель при первом запуске, дальше работают офлайн.

## Сценарии

1. **Заполнение договора** — загрузите паспорт и реквизиты, приложение извлечёт поля
   и заполнит `templates/dogovor_template.docx`.
2. **Анализ рисков договора** — LLM прочитает договор и вернёт список рисков,
   результат можно **скачать отчётом в `.docx`**.
3. **Вопрос по документу** — задайте вопрос, модель ответит по содержимому файла.
4. **Чек-лист договора** — проверка по обязательным условиям (услуги, поставка, аренда,
   подряд, заём, конфиденциальность) с процентом готовности.
5. **Сканы и фото** — локальный **OCR на русском** (Tesseract) распознаёт PDF-сканы
   и изображения, дальше работают все сценарии.

Повторные запросы по тому же документу берутся из кэша (анализ рисков: 41 с → мгновенно).

Без установленной модели извлечение реквизитов и заполнение договора работают
детерминированно; анализ рисков и вопросы переходят на эвристику (`fallback`).

## Как доказать, что приложение офлайн

1. `./run.sh` — по умолчанию `VANYA_OFFLINE=1`.
2. Отключите сеть (Wi-Fi / кабель) — приложение продолжает работать.
3. Попытка соединения с любым адресом, кроме `127.0.0.1`, вернёт ошибку.

Для отладки без жёсткого офлайн-режима: `./run.sh --no-offline`.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `VANYA_MODEL` | `qwen2.5:3b` | модель Ollama |
| `VANYA_OLLAMA_URL` | `http://127.0.0.1:11434` | адрес Ollama |
| `VANYA_WORKSPACE` | `./workspace` | папка с документами |
| `VANYA_PORT` | `8765` | порт веб-приложения |
| `VANYA_OFFLINE` | `1` | жёсткий офлайн (блок не-loopback) |
| `VANYA_CACHE` | `1` | кэш ответов LLM (`0` — отключить) |
| `VANYA_LLM_EXTRACT` | `1` в `run.sh` | дозаполнение реквизитов моделью (в тестах `0`) |

## Ограничения демо

- Модель работает на CPU: на 8 ГБ ОЗУ скорость ответа невысокая, длинные документы
  обрабатываются медленно.
- Качество анализа рисков ограничено возможностями локальной модели.
- Это демо, а не законченный продукт: без гарантий юридической корректности результатов.
- Тестовые документы в `samples/` содержат вымышленные данные.
