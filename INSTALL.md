# Установка ЛексЛока: подробная инструкция

Здесь по шагам описано, как поставить ЛексЛок на Windows, macOS и Linux, что при этом
происходит на компьютере и что делать, если что-то пошло не так. Краткая версия — в
[README.md](README.md).

Есть два способа:

1. **Установочный скрипт (рекомендуется).** Одна команда в терминале. Всегда ставит
   свежую версию, сам докачивает всё нужное, при обрыве связи продолжает с места обрыва.
2. **Готовые пакеты** со страницы Releases. Внутри уже есть Python, Ollama и модель,
   интернет при установке не нужен. Файлы большие (около 2 ГБ и больше), а при запуске
   система может ругаться на неподписанное приложение.

Если не знаете, что выбрать, берите скрипт. Пакеты нужны, когда интернета нет совсем или
он очень нестабильный.

## Что нужно от компьютера

| | Минимум | Комфортно |
|---|---|---|
| ОЗУ | 8 ГБ | 16 ГБ |
| Свободное место | 5 ГБ | 10 ГБ |
| Процессор | любой 64-бит, видеокарта не нужна | |
| Система | Windows 10/11, macOS 12+, Linux x86_64 | |
| Интернет | только при установке скриптом (около 2 ГБ) | |

Модель подбирается по памяти автоматически. Если на Windows ОЗУ меньше 10 ГБ, ставится
лёгкая `qwen2.5:1.5b`, иначе `qwen2.5:3b`. На Linux и macOS выбор делает
`scripts/check_ram.py --recommend` по свободной памяти. Права администратора на Windows
не нужны. На Linux понадобится пароль `sudo` для установки Ollama (см. ниже).

## Способ 1. Установочный скрипт

Общая схема одинакова везде:

1. скрипт скачивает свежий код проекта с GitHub (ветка `main`);
2. ставит менеджер `uv`, который сам подтягивает нужный Python 3.12;
3. ставит Ollama, программу для запуска модели на вашем компьютере;
4. создаёт окружение `.venv` и ставит в него зависимости (всё внутри папки программы,
   ваш системный Python не трогается);
5. по возможности ставит Tesseract для чтения сканов (необязательно);
6. скачивает модель (самая долгая часть);
7. добавляет ярлык «ЛексЛок» и запускает программу, браузер открывается на
   `http://127.0.0.1:8765`.

Повторный запуск безопасен: что уже стоит, заново не качается.

### Windows

**Шаг 1. Откройте PowerShell.** Нажмите «Пуск», наберите `PowerShell`, откройте
«Windows PowerShell» обычным щелчком. Запускать от имени администратора **не нужно**.
Откроется окно с синим или чёрным фоном и строкой вида `PS C:\Users\Имя>`.

**Шаг 2. Вставьте команду и нажмите Enter.** Вставка в PowerShell: правый клик мышью по
окну или `Ctrl+V`.

```powershell
irm https://raw.githubusercontent.com/workihi53-max/lexlock/main/install-windows.ps1 | iex
```

Команда скачивает небольшой скрипт `install-windows.ps1` и сразу выполняет его.

**Шаг 3. Ждите.** В окне будут сообщения на русском. Что происходит по порядку:

| Что видите | Что делается | Сколько |
|---|---|---|
| `==> ЛексЛок: установка в C:\Users\<имя>\AppData\Local\LexLock` | создаётся папка программы | секунды |
| `==> Скачиваю свежий код (main)` | качается zip с кодом (несколько МБ) | до минуты |
| `[1/6]` uv | ставится менеджер Python-окружений в профиль пользователя | 1 минута |
| `[2/6]` Ollama | качается `OllamaSetup.exe` (~500 МБ), проверяется цифровая подпись, ставится тихо | 2–10 минут |
| `[3/6]` Python-окружение | создаётся `.venv`, ставятся зависимости | 2–5 минут |
| `[4/6]` Tesseract | через `winget`, для сканов. Не получилось — не страшно | 1–3 минуты |
| `[5/6]` модель | качается `qwen2.5:1.5b` или `3b` (1–2 ГБ). Дольше всего | 5–40 минут |
| `[6/6]` шаблон и примеры | готовится шаблон договора и образцы | секунды |

Закрывать окно во время установки нельзя. Если связь оборвалась, скрипт сам повторит
загрузку: до 15 попыток для кода и до 30 для модели, с докачкой с места обрыва.

**Шаг 4. Готово.** Появится «Готово. ЛексЛок запущен и открылся в браузере.», откроется
страница `http://127.0.0.1:8765`, а в меню «Пуск» появится ярлык «ЛексЛок».

**Где что лежит**

| | Путь |
|---|---|
| Программа | `C:\Users\<имя>\AppData\Local\LexLock` |
| Ваши документы | `C:\Users\<имя>\AppData\Local\LexLock\workspace` |
| Журнал установки | `C:\Users\<имя>\AppData\Local\LexLock\install.log` |
| Журнал работы | `lexlock.log` в папке программы |

Папку `AppData` Windows скрывает. Чтобы быстро открыть: нажмите `Win+R`, введите
`%LOCALAPPDATA%\LexLock`, Enter.

**Дальше запускать** через ярлык «ЛексЛок» в меню «Пуск». Чёрного окна не будет.

**Если не сработало**

- *Красная ошибка про политику выполнения скриптов.* Выполните в том же окне и повторите
  команду установки:
  ```powershell
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  ```
  Действует только до закрытия окна, систему не меняет.
- *«Не удалось скачать код. Проверьте интернет».* Нет связи с `github.com`. Проверьте
  браузером, зайдите на `https://github.com/workihi53-max/lexlock`. За корпоративным
  прокси или без доступа к GitHub используйте [готовый пакет](#windows-офлайн-zip).
- *Антивирус заблокировал команду или `OllamaSetup.exe`.* Временно разрешите, либо
  поставьте [офлайн-пакет](#windows-офлайн-zip).
- *«Установка компонентов завершилась с кодом N».* Откройте `install.log` в папке
  программы, последние строки покажут причину. Затем просто запустите команду ещё раз.
- *Установка прервалась на модели.* Запустите команду снова: докачка продолжится, а
  уже скачанное не повторится.
- *Не поставился Tesseract.* Всё работает, кроме чтения сканов. Поставить вручную:
  <https://github.com/UB-Mannheim/tesseract/wiki> (при установке отметьте русский язык).

**Без команды, мышкой:** на странице репозитория нажмите **Code → Download ZIP**,
распакуйте архив, затем правый клик по `packaging\windows\install.ps1` →
«Выполнить с помощью PowerShell».

### macOS

**Шаг 1. Откройте «Терминал».** Finder → «Программы» → «Утилиты» → «Терминал». Либо
`Cmd+Пробел`, наберите `Терминал`.

**Шаг 2. Вставьте команду и нажмите Return.**

```bash
curl -fsSL https://raw.githubusercontent.com/workihi53-max/lexlock/main/bootstrap.sh | bash
```

Установка Xcode или Command Line Tools **не требуется**. Если macOS всё же покажет окно
с предложением их поставить, это связано не с ЛексЛоком; можно отказаться.

**Шаг 3. Ждите.** Что происходит:

| Этап | Что делается |
|---|---|
| Скачивание кода | tarball ветки `main` распаковывается в `~/lexlock` |
| uv | ставится в `~/.local/bin`, он же подтягивает Python 3.12 |
| Ollama | если есть Homebrew, выполняется `brew install ollama`. Если нет, скачивается `Ollama.app` (~200 МБ) в `/Applications` или `~/Applications` |
| Окружение | `~/lexlock/.venv` и зависимости |
| OCR | при наличии Homebrew ставятся `tesseract` и `tesseract-lang`. Без Homebrew этот шаг пропускается, сканы читаться не будут |
| Модель | скачивается `qwen2.5:3b` или лёгкая `1.5b` при малой памяти, до 30 попыток с докачкой |
| Ярлык | создаётся `~/Applications/ЛексЛок.app`, он виден в Launchpad |
| Запуск | сервер стартует, открывается браузер |

Во время работы может появиться системное окно с вопросом, разрешить ли доступ к сети
или файлам. Разрешайте: это Ollama. Если ничего не появилось, всё нормально.

**Где что лежит**

| | Путь |
|---|---|
| Программа | `~/lexlock` (папка `lexlock` в домашней папке) |
| Ваши документы | `~/lexlock/workspace` |
| Ярлык | `~/Applications/ЛексЛок.app`, Launchpad |
| Модели Ollama | `~/.ollama/models` |

**Дальше запускать** через Launchpad: значок «ЛексЛок». Либо в терминале `~/lexlock/run.sh`.

**Если не сработало**

- *`curl: (6) Could not resolve host` или `(7)`.* Нет интернета или заблокирован
  GitHub. Проверьте сеть и повторите.
- *Ollama не поставилась.* В конце будет предупреждение. Скачайте приложение с
  <https://ollama.com/download>, откройте его один раз, затем повторите ту же команду.
- *Модель не скачалась.* Повторите команду, докачка продолжится. Либо вручную:
  ```bash
  ~/lexlock/.venv/bin/python ~/lexlock/scripts/check_ram.py --recommend   # какая модель подходит
  ollama pull qwen2.5:1.5b
  ```
- *Значок ЛексЛок не открывается («не удалось проверить разработчика»).* Приложение не
  подписано Apple. Один раз: правый клик по значку в «Программы» → «Открыть» → «Открыть».
- *Страница не открылась сама.* Откройте <http://127.0.0.1:8765> вручную.
- *Читать сканы нужно, а OCR нет.* Поставьте Homebrew (<https://brew.sh>), затем
  `brew install tesseract tesseract-lang`.

### Linux

**Шаг 1. Откройте терминал** (обычно `Ctrl+Alt+T`).

**Шаг 2. Вставьте команду и нажмите Enter.**

```bash
curl -fsSL https://raw.githubusercontent.com/workihi53-max/lexlock/main/bootstrap.sh | bash
```

Нужны `curl` и `tar` (в большинстве дистрибутивов уже есть). Если `curl` нет:
`sudo apt install curl` (Debian/Ubuntu), `sudo dnf install curl` (Fedora),
`sudo pacman -S curl` (Arch/Manjaro).

**Шаг 3. Ждите.** Что происходит:

| Этап | Что делается |
|---|---|
| Окно приветствия | если есть `kdialog`/`zenity`/`xmessage`, появится окно «ЛексЛок сейчас установится…». Без них сообщения идут в терминал |
| Код | tarball ветки `main` распаковывается в `~/lexlock` |
| uv | ставится в `~/.local/bin`, он подтягивает Python 3.12 |
| Ollama | официальный скрипт `ollama.com/install.sh`. **Попросит пароль `sudo`**, это нормально: Ollama ставится как системная служба |
| Окружение | `~/lexlock/.venv` и зависимости |
| OCR | на Debian/Ubuntu: `sudo apt-get install tesseract-ocr tesseract-ocr-rus`. На других дистрибутивах шаг пропускается, см. ниже |
| Модель | скачивается `qwen2.5:3b` или лёгкая `1.5b`, до 30 попыток с докачкой |
| Ярлык | `~/.local/share/applications/lexlock.desktop`, значок «ЛексЛок» в меню приложений |
| Запуск | сервер стартует, браузер открывается через `xdg-open` |

Пароль при вводе не отображается: ни точек, ни звёздочек. Это нормально, вводите и жмите
Enter.

**Где что лежит**

| | Путь |
|---|---|
| Программа | `~/lexlock` |
| Ваши документы | `~/lexlock/workspace` |
| Ярлык | меню приложений, файл `~/.local/share/applications/lexlock.desktop` |
| Модели Ollama | `/usr/share/ollama/.ollama/models` (служба) или `~/.ollama/models` |

**Дальше запускать** через меню приложений («ЛексЛок») либо `~/lexlock/run.sh`.
Закрыть вкладку браузера недостаточно, см. [Как запускать и останавливать](#как-запускать-и-останавливать).

**Если не сработало**

- *Ollama не поставилась (нет `sudo`, нет `systemd`, нет прав).* Скрипт выведет
  предупреждение. Поставьте Ollama вручную с <https://ollama.com/download> (в Arch/Manjaro:
  `sudo pacman -S ollama`) и повторите команду.
- *Нет OCR на Fedora/Arch.* Поставьте вручную:
  - Fedora: `sudo dnf install tesseract tesseract-langpack-rus`
  - Arch/Manjaro: `sudo pacman -S tesseract tesseract-data-rus`
- *Браузер не открылся.* Откройте <http://127.0.0.1:8765> вручную.
- *Скрипт не нашёл `uv` после установки.* Закройте терминал, откройте новый, повторите
  команду.
- *Проверить, что работает:*
  ```bash
  curl http://127.0.0.1:8765/api/health        # ответ программы, должен быть "ok": true
  curl http://127.0.0.1:11434/api/tags         # отвечает ли Ollama
  ollama list                                  # какие модели скачаны
  ```

**Без команды, мышкой:** скачайте [`bootstrap.sh`](https://raw.githubusercontent.com/workihi53-max/lexlock/main/bootstrap.sh),
правый клик → «Свойства» → «Разрешить выполнение файла», откройте двойным кликом.

**Из клона репозитория (для разработчиков):**

```bash
git clone https://github.com/workihi53-max/lexlock.git && cd lexlock
./install.sh        # --skip-model пропустить модель, --no-ocr без OCR, --model ИМЯ выбрать модель
./run.sh
```

## Способ 2. Готовые пакеты

Страница: <https://github.com/workihi53-max/lexlock/releases>. Берите последнюю версию.
Пакеты собираются автоматически при публикации тега `vX.Y.Z`.

**Что внутри:** Python, все зависимости, Ollama и модель. Интернет не нужен ни при
установке, ни при работе. Размер зависит от модели, в пределах 2 ГиБ на файл и более.

**Чего нет:** программы Tesseract для распознавания сканов. Если нужны сканы, поставьте
Tesseract отдельно (см. разделы выше). Основные сценарии работают без него.

Пакеты не подписаны, поэтому при первом запуске система покажет предупреждение. Это
ожидаемо, ниже написано, как его обойти.

Данные пакеты, в отличие от скрипта, **не обновляются сами**. Чтобы получить новую
версию, скачайте новый пакет.

### Windows: офлайн-zip

Файл: `LexLock-<версия>-win-offline.zip`.

1. Скачайте файл и **распакуйте целиком** в удобную папку, например `C:\LexLock`: правый
   клик → «Извлечь всё». Не запускайте из окна архива. Выбирайте короткий путь без
   кириллицы, это снижает риск ошибок.
2. Откройте папку и дважды щёлкните **«Запустить ЛексЛок.bat»**.
3. Если Windows показала синее окно «Защитили ваш компьютер»: «Подробнее» →
   «Выполнить в любом случае».
4. Появится свёрнутое окно консоли (его не закрывайте, оно держит программу) и откроется
   браузер на `http://127.0.0.1:8765`. Первый запуск до минуты.

Документы лежат в папке `workspace` рядом с программой. Порты: 8765 (интерфейс) и 11435
(модель, только внутри компьютера).

Остановить: кнопка «Остановить» в окне ЛексЛока. Консольное окно закроется само и
выгрузит модель из памяти.

### macOS: офлайн-dmg

Файлы (выберите по процессору):

- `LexLock-<версия>-mac-arm64-offline.dmg` для Apple Silicon (M1, M2, M3, M4);
- `LexLock-<версия>-mac-x86_64-offline.dmg` для Intel.

Какой у вас процессор: меню Apple → «Об этом Mac». «Чип Apple…» это arm64, «Процессор
Intel» это x86_64.

1. Откройте скачанный `.dmg` и перетащите «ЛексЛок» в «Программы».
2. Первый запуск: правый клик по «ЛексЛок» → «Открыть» → «Открыть». Обычный двойной
   щелчок в первый раз покажет «не удалось проверить разработчика».
3. Откроется браузер на `http://127.0.0.1:8765`.

Если после правого клика кнопки «Открыть» нет: «Системные настройки» → «Конфиденциальность
и безопасность» → внизу «Всё равно открыть». Либо в терминале:

```bash
xattr -dr com.apple.quarantine /Applications/ЛексЛок.app
```

Документы: `~/LexLock/workspace`. Журнал: `~/LexLock/lexlock.log`.

### Linux: офлайн-AppImage

Файл: `LexLock-<версия>-linux-offline.AppImage` (только x86_64).

```bash
chmod +x LexLock-*-linux-offline.AppImage
./LexLock-*-linux-offline.AppImage
```

Либо через файловый менеджер: правый клик → «Свойства» → «Разрешить выполнение файла»,
затем двойной щелчок.

Если пишет `cannot mount AppImage` или `fuse: ...` (нет FUSE), запустите так:

```bash
./LexLock-*-linux-offline.AppImage --appimage-extract-and-run
```

или поставьте FUSE: `sudo apt install libfuse2` (Debian/Ubuntu), `sudo pacman -S fuse2`
(Arch/Manjaro).

Документы: `~/LexLock/workspace` (обратите внимание: с большой буквы, это не та папка
`~/lexlock`, которую создаёт скрипт). Журнал: `~/LexLock/lexlock.log`. Если программа
не открылась, смотрите именно его.

### Тонкие установщики

В Releases есть и обычные установщики: `LexLock-<версия>.dmg`, `LexLock-<версия>-x86_64.AppImage`,
`LexLock-<версия>-win-setup.exe`. Они маленькие, но при первом запуске сами докачивают
Ollama и модель, то есть интернет нужен. Для вас это то же самое, что установочный
скрипт, только с мышиным интерфейсом. Если есть терминал, проще взять скрипт.

## Как запускать и останавливать

| | Запуск | Остановка |
|---|---|---|
| Windows | ярлык «ЛексЛок» в «Пуск» | кнопка «Остановить» в окне |
| macOS | Launchpad → «ЛексЛок» | кнопка «Остановить» |
| Linux | меню приложений → «ЛексЛок», либо `~/lexlock/run.sh` | кнопка «Остановить» |

Закрытие вкладки браузера программу не останавливает: сервер и модель продолжают
занимать память. Остановить можно кнопкой «■ Остановить» вверху справа, иконкой в трее
(если она есть) или перезагрузкой.

Адрес всегда один: <http://127.0.0.1:8765>. Если вкладку закрыли, а программа работает,
откройте адрес снова.

## Если что-то не так

**Где смотреть, что случилось**

| Система | Установка | Работа |
|---|---|---|
| Windows (скрипт) | `%LOCALAPPDATA%\LexLock\install.log` | `lexlock.log` в папке программы |
| Windows (zip) | | отдельного журнала нет; запустите `.bat` из `cmd` и смотрите вывод |
| macOS (скрипт) | вывод в терминале | `~/Library/Logs/LexLock.log` для `.app` из dmg |
| macOS/Linux (пакет) | | `~/LexLock/lexlock.log` |
| Linux (скрипт) | вывод в терминале | запустите `~/lexlock/run.sh` в терминале, ошибки будут видны |

**Типичные ситуации**

| Симптом | Причина | Что делать |
|---|---|---|
| Страница `127.0.0.1:8765` не открывается | сервер не запущен или ещё стартует | подождите минуту, запустите ярлык заново; проверьте `curl http://127.0.0.1:8765/api/health` |
| «Address already in use», порт 8765 занят | ЛексЛок уже запущен, либо порт занят другой программой | откройте адрес в браузере; иначе перезагрузите компьютер. Другой порт: переменная `LEXLOCK_PORT` |
| Ответы очень медленные | слабый процессор, мало ОЗУ, модель ушла в своп | поставьте лёгкую модель, см. ниже; закройте браузерные вкладки и тяжёлые программы |
| «Модель недоступна» в интерфейсе | Ollama не запущена или модель не скачана | `ollama list` должен показать модель; если пусто, `ollama pull <имя>`. Реквизиты и заполнение договора работают и без модели |
| Установка оборвалась на скачивании | нестабильная сеть | запустите ту же команду, докачка продолжится |
| Проверка ОЗУ: «свободной памяти мало» | предупреждение, не ошибка | закройте лишнее; если тормозит, лёгкая модель |
| Сканы не читаются | нет Tesseract | поставьте его, см. разделы выше |

**Сменить модель на более лёгкую**

```bash
ollama pull qwen2.5:1.5b
```

Затем укажите её: на macOS/Linux запишите имя в `~/lexlock/.lexlock_model` или задайте
`LEXLOCK_MODEL=qwen2.5:1.5b` перед запуском; на Windows запишите имя в файл
`.lexlock_model` в папке программы. Модель `qwen2.5:1.5b` идёт под лицензией Apache 2.0.

**Проверить, что наружу ничего не уходит:** отключите интернет. ЛексЛок продолжит
работать как раньше. Все сетевые соединения вне `127.0.0.1` блокируются самой программой.

**Ничего не помогло:** соберите `install.log` или `lexlock.log` и напишите в Issues
репозитория: <https://github.com/workihi53-max/lexlock/issues>. Не прикладывайте
документы: журнал их не содержит, но проверьте файл перед отправкой.

## Обновление

- **Windows:** выполните команду установки ещё раз. Скрипт скачает свежий код и перезапишет
  программу, `workspace` и модель не тронет.
- **macOS и Linux (скрипт):** повторный запуск `bootstrap.sh` код **не обновляет**, если
  папка `~/lexlock` уже есть. Чтобы обновиться, сначала скопируйте документы из
  `~/lexlock/workspace`, затем удалите `~/lexlock` и снова выполните команду. Модель
  при этом не скачивается заново: она лежит в хранилище Ollama (`~/.ollama`).
- **Готовые пакеты:** скачайте новый пакет и замените старый. Документы из
  `workspace` (Windows) или `~/LexLock/workspace` (macOS/Linux) перенесите или оставьте
  на месте.

## Полное удаление

**Windows**

1. Удалите папку `%LOCALAPPDATA%\LexLock` (сначала остановите программу).
2. Удалите ярлык `ЛексЛок` из меню «Пуск» (`%APPDATA%\Microsoft\Windows\Start Menu\Programs`).
3. По желанию: «Параметры» → «Приложения» → «Ollama» → «Удалить». Модели Ollama лежат в
   `%USERPROFILE%\.ollama`.

**macOS**

```bash
rm -rf ~/lexlock ~/Applications/ЛексЛок.app ~/LexLock
rm -rf ~/.ollama                      # модели; пропустите, если Ollama нужна другим программам
rm -rf ~/Library/Logs/LexLock.log ~/Library/"Application Support"/LexLock
```

Если ставился `Ollama.app`, перетащите его из «Программ» в корзину.

**Linux**

```bash
rm -rf ~/lexlock ~/LexLock ~/.local/share/applications/lexlock.desktop \
       ~/.local/share/icons/hicolor/256x256/apps/lexlock.png
# Ollama и её модели, только если они не нужны другим программам:
sudo systemctl disable --now ollama
sudo rm -f /etc/systemd/system/ollama.service "$(command -v ollama)"
sudo rm -rf /usr/share/ollama
```

Перед удалением `~/lexlock` и `~/LexLock` заберите свои документы из `workspace`.

## Параметры установки

Флаги `install.sh` (macOS/Linux; через `bootstrap.sh` не передаются, используйте клон):

| Флаг | Что делает |
|---|---|
| `--skip-model` | не качать модель |
| `--no-ocr` | не ставить Tesseract и PyMuPDF |
| `--model ИМЯ` | выбрать модель вместо автоподбора |

Переменные окружения:

| Переменная | Что делает |
|---|---|
| `LEXLOCK_DIR` | куда `bootstrap.sh` ставит программу (по умолчанию `~/lexlock`) |
| `LEXLOCK_BRANCH` | другая ветка вместо `main` |
| `LEXLOCK_MODEL` | модель Ollama |
| `LEXLOCK_PORT` | порт интерфейса (по умолчанию 8765) |
| `LEXLOCK_CODE_REF` | Windows: ветка для подтягивания свежего кода |
| `LEXLOCK_NO_REFRESH=1` | Windows: не скачивать свежий код |

Переменную нужно передавать самому `bash`, а не `curl`:

```bash
curl -fsSL https://raw.githubusercontent.com/workihi53-max/lexlock/main/bootstrap.sh | LEXLOCK_DIR=$HOME/apps/lexlock bash
```
